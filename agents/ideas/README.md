# Ideas

When to use: Parking an idea, or clearing one after a meeting.

Not the work queue. Classify each idea before it becomes a plan:
product, architecture, tooling, or needs an architecture meeting.

Once an idea has a goal and acceptance, it is a plan on
[`priority.md`](../priority.md), not a row here.

After a meeting, remove an idea that is obsolete, decided, or
done.
