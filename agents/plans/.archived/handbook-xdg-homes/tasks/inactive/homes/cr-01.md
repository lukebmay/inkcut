# cr-01

**Result:** no defect.

## Summary

The change matches the task. One resolver reads the XDG home
variables. Config stays live, state is pinned on first resolve,
and new logs use the state home. The guide was not edited.

## Checks

- A set `INKCUT_CONFIG_HOME` is that path. `config_home()` returns
  it with nothing appended, and the device plugin file is
  `{that path}/inkcut.device.json`.
- With the app variable unset, `$XDG_CONFIG_HOME/inkcut` is the
  config home and the plugin file is
  `{that path}/inkcut.device.json`.
- With both unset, the path is `~/.config/inkcut/{plugin id}.json`.
  The test points `HOME` at a temporary directory and expects
  `{HOME}/.config/inkcut/inkcut.job.json`. The code joins
  `expanduser('~')`, `.config`, `inkcut`, and `{plugin id}.json`.
- `init_logging` creates `{state home}/logs/inkcut.txt` and leaves
  an existing `{config home}/logs/inkcut.txt` byte for byte.
  Nothing in the product deletes or moves that old directory.
  Help / Logs uses `log_dir()`, and the startup error dialog in
  `inkcut/core/plugin.py` does too.
- Product `.py` and `.enaml` files name an XDG home variable only
  in `inkcut/core/homes.py`. The same search over shell, JSON,
  TOML, cfg, ini, and spec files finds no other product reader.
- `data_home`, `cache_home`, and `runtime_dir` create no
  directory. Runtime raises when both variables are unset. The
  resolver does not mention `/tmp`.
- `agents/project.md` and `agents/architecture.md` have no diff.

Re-ran `QT_QPA_PLATFORM=offscreen python3 -m pytest
tests/test_homes.py`: 14 passed. Every test in that file uses the
temporary `HOME` fixture. After the run, `~/.config/inkcut` had
the same mtime, `state-home` was still absent, and
`~/.config/inkcut/logs` had the same mtime.
`~/.local/state/inkcut` was not created.

## Context

The pin is `{config home}/state-home`. There is no install
command, so the first `state_home()` writes the absolute path.
A later state variable does not move logs while that file is the
one read. Data stays live until an install exists. The app does
not call `data_home`, `cache_home`, or `runtime_dir`.

## Outside this change

`inkcut/core/` has more than one source file and no directory
index. The handbook Source files rule requires the index. The
other files were already there before `homes.py`. This review
does not add the index. File that gap separately. Do not fold it
into this task.
