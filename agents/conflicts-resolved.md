# Conflicts resolved

**Owner:** agent. The allowed edit is appending a retired row.

## These rows are not rules

The rows below are **not rules**. They are decisions made at
particular moments to iteratively shape the actual living rules
in [`architecture.md`](./architecture.md) and the rest of the
handbook.

Living rules are [`architecture.md`](./architecture.md),
[`acceptance.md`](./acceptance.md), any project-declared stricter
file, [`glossary.md`](./glossary.md) for words, and the selected
OpSet document when the project has one. Architecture is a current
belief and can change. When a row here and a living rule disagree,
the living rule is what we believe now. A row here does not keep,
restore, or block a behavior.

**Do not delete this file. Do not delete, weaken, or rewrite
this section.** It stays when it is inconvenient. Removing it
does not turn these rows into rules, and it does not erase the
decisions. If this section is missing or weaker than the
paragraph above, restore it before any other edit to this file.
The order is catalog `general.md` Conflicts.

Do not delete a row. Do not rewrite a decision so that it reads
as the current rule. When architecture changes later, leave the
old decision as it was. Append a new live contradiction to
[`conflicts.md`](./conflicts.md) instead.
