# Conflicts

**Owner:** agent. Agents read and write this file.

Leftover names and contradictions. This is not a second architecture,
glossary, or plan. Target words: [`glossary.md`](./glossary.md). Target
system: [`architecture.md`](./architecture.md). How to run: catalog
`general.md`.

A row may have **no resolution yet**. Add it anyway in the same turn
you find it, and **tell the human** (leftover, where it lives, why
it contradicts the handbook). Then, as soon as you can name the
fix, write or extend a plan and put that plan on
[`priority.md`](./priority.md). If a plan already owns the gap, link
it. Do not mint more of the leftover name while waiting.

**Read as** is the handbook word and a pointer to
[`architecture.md`](./architecture.md) or
[`glossary.md`](./glossary.md). It is not a place to write new
architecture.

Do not implement product work that **depends on** an open
contradiction until the human has resolved it (or accepted the
resolving plan's approach). Closing leftover code after that
acceptance is the plan, not a second architecture.

Status: **open** (noted, fix unknown) · **resolving** (a plan owns
it) · **closed** (the leftover is gone or the reading rule is enough
and no further hunt is queued).
